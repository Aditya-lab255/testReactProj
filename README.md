# Tic-Tac-Toe Game (React + TypeScript + Bun)

A modern, responsive Tic-Tac-Toe game built with **React 19**, **TypeScript**, **Vite**, and **Bun**.

## 🎮 Features

- **Two Game Modes**:
  - **vs Computer (AI)**: Play against a computer opponent with two difficulty options:
    - *Easy*: Casual random moves
    - *Unbeatable AI*: Powered by the **Minimax algorithm**
  - **2 Players**: Classic local pass-and-play mode
- **Dynamic Scoreboard**: Tracks Player X wins, Player O wins, and Draws
- **Move History & Undo**: Step back moves if you make a mistake
- **Winning Highlights**: Animated glowing highlights on winning combinations
- **Modern Responsive UI**: Dark glassmorphic theme with neon accents, responsive for mobile and desktop

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (v1.0+)

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Aditya-lab255/testReactProj.git
cd testReactProj
bun install
```

### Development Server

Start the local development server:

```bash
bun dev
```

### Build for Production

Compile and bundle for production:

```bash
bun run build
```

### Preview Production Build

Preview the production build locally:

```bash
bun run preview
```

### Linting

Lint code with Oxlint:

```bash
bun run lint
```
